## 安装与启用

1. 从 [JO-IME Releases](https://github.com/JO-Beacon/JO-IME/releases) 下载 APK。安装包只有 ARM64，要求 Android 9.0 及以上。
2. 安装并打开 **JO-IME**，点击 **启用输入法**，在系统列表里打开 JO-IME。
3. 返回应用，点击 **选择输入法**，选择 JO-IME。
4. 等首次词库准备好。中文词库随应用提供，不用先下载语音、手写或联想模型才能打字。

升级同一签名的 JO-IME，直接装新包即可保留数据。

## 键盘与输入

键盘上方是候选栏和工具栏。

- **打开菜单**：点键盘上方的 JO-IME 图标。
- **切换语言**：点语言键在中文和英文之间切换；长按语言键打开语言列表。
- **数字与符号**：点 `123` 打开数字页，点 `!@#` 打开符号页。
- **空格**：点按上屏；长按开始语音输入，松手结束。
- **回车**：有未完成输入时先处理输入；空闲时按输入框要求执行换行、发送、搜索或下一项。
- **退格**：删除光标前的字；打字中上滑可清空。

中文只有全拼 26 键一种输入方式，不需要在方案之间切换。

## 候选与联想

- 点候选词上屏；点候选栏右侧的展开按钮查看更多。
- 候选注释在候选旁显示拼音或释义，可在 **设置 → 候选词 → 候选注释** 里切换「自动 / 显示 / 隐藏」，内容选「拼音 / 释义」。选释义会自动下载释义词典。
- 联想在词上屏后给出下一个词。**设置 → 智能联想** 里可以开关、调联想行为、换模型。
- 长按候选后的「删除」用于移除对应的学习词条，不是撤销刚才的选词。

## 语音与手写

- **语音**：长按空格说话，松手出字。首次使用要先在 **设置 → 语音转文本** 里下载模型；也可以填自己的在线接口。
- **手写**：在输入模式里切到手写板，支持中文、英文和数学公式（识别成 LaTeX）。手写模型在 **设置 → 手写 → 已安装的手写模型** 里下载。
- **字幕**：桌面「字幕」图标或键盘菜单进入，把周围的话实时转成字幕，可自动分说话人并保存记录。

## 剪贴板与同步

- 剪贴板记录在键盘的剪贴板面板里，支持固定、分组和搜索。
- **设置 → 剪贴板与同步** 里可以开验证码自动复制、和电脑扫码配对同步剪贴板。

## 词库与短语

**设置 → 词库** 分四个页签：

| 页签 | 用途 |
|---|---|
| 我的短语 | 添加、修改、删除短语，设置编码和可选权重。 |
| 导入词库 | 导入 `.scel`、`.txt`、`.dict.yaml`、`.json` 词库，启停和删除已导入的词库。 |
| 删掉的候选 | 查看被屏蔽的候选并放回。 |
| 查词 | 查词库内容。 |

升级会检查随应用提供的中文词库；需要替换的内置文件会先备份。

## 外观与按键

- **设置 → 主题与外观**：深浅模式、配色、玻璃效果、透明度与模糊、桌面图标、背景图片。
- **设置 → 按键效果**：按键音、音色、音量，振动模式、时长和振幅，按键动效与键内炫光。
- **设置 → 按键与手势**：角标输入方式、长按气泡、反转上下滑、删除键清空方式、Z X C V 快捷键、滑动移光标、长按空格、各时长与距离、手写停顿与公式标记、按键字号。
- **设置 → 键盘布局**：26 键的键位与显示、自定义布局、按键符号、分体键盘、数字键盘。

## 已知限制

- 只有 ARM64 安装包。
- 中文只有全拼 26 键；没有九键、双拼、五笔、笔画、仓颉、注音。
- 语言只有中文和英文。
